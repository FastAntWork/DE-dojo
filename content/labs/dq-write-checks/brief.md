# Задача: написать проверки, которые заметят порчу

Эта лаба устроена наоборот. Ничего не сломано — данные на стенде чистые.
Сломается позже, и вопрос в том, узнаешь ли ты об этом раньше заказчика.

## Что есть на стенде

- `customers` — 5 000 клиентов, справочник.
- `orders` — 50 000 заказов: `order_id`, `customer_id`, `status`, `amount`,
  `created_at`.
- `dq_checks(name, query)` — **реестр проверок. Его и надо заполнить.**

Допустимые статусы: `new`, `paid`, `shipped`, `cancelled`.

## Контракт проверки

Проверка — это `SELECT`, возвращающий **плохие строки**. Пусто значит проверка
прошла. Ровно так устроены тесты dbt, и ровно поэтому свою проверку написать
тривиально: достаточно SQL, находящего нарушения.

В реестре уже лежит пример:

```sql
SELECT name, query FROM dq_checks;
```

Добавляются проверки обычным INSERT:

```sql
INSERT INTO dq_checks (name, query) VALUES (
    'orders_amount_positive',
    'SELECT order_id FROM orders WHERE amount <= 0'
);
```

## Задача

Написать набор проверок, замечающий шесть видов порчи. Чекер испортит данные
шестью разными способами — каждый в откатываемой транзакции — и посмотрит,
сработала ли хоть одна твоя проверка.

Что будет сломано:

1. **Задвоение ключа** — один `order_id` встретится дважды.
2. **Пропуск в обязательном поле** — у части заказов исчезнет `customer_id`.
3. **Значение вне допустимого диапазона** — появится отрицательная сумма.
4. **Статус вне списка** — появится значение, которого нет в четвёрке
   допустимых.
5. **Битая ссылка** — заказ будет ссылаться на несуществующего клиента.
6. **Устаревание** — свежие данные пропадут, и максимум `created_at` уедет в
   прошлое больше чем на двое суток.

## Что считается решённым

1. **Каждый из шести видов порчи замечен** хотя бы одной проверкой.
2. **Ни одной ложной тревоги:** на чистых данных все проверки возвращают ноль
   строк. Проверка, срабатывающая всегда, ловит всё и не значит ничего.
3. **Пример из реестра сохранён** и продолжает работать.

## Подсказка по формату

Запросы хранятся текстом, поэтому кавычки внутри нужно удваивать:

```sql
INSERT INTO dq_checks (name, query) VALUES (
    'orders_status_known',
    'SELECT order_id FROM orders WHERE status NOT IN (''new'', ''paid'')'
);
```

Либо использовать долларовые кавычки — с ними удобнее:

```sql
INSERT INTO dq_checks (name, query) VALUES (
    'orders_status_known',
    $q$SELECT order_id FROM orders WHERE status NOT IN ('new', 'paid')$q$
);
```
