# Выгрузка всех страниц с ретраями

Напиши функцию `fetch_all(transport, limit=100, max_attempts=5)`, которая
забирает из API **все** записи, переживая временные сбои и не добивая
источник повторами.

```python
records = fetch_all(transport)
```

Настоящего HTTP здесь нет: вместо него — объект `transport` с одним методом.
Так задача остаётся про логику выгрузки, а не про библиотеку.

## Контракт транспорта

```python
response = transport.get(cursor=None, limit=100)
```

Возвращает объект `Response` с полями:

- `status` — целое: `200`, `429`, `500`, `503`, `400`, `401`;
- `items` — список записей (при `status == 200`);
- `next_cursor` — метка следующей страницы или `None`, если страниц больше
  нет;
- `retry_after` — сколько секунд просил подождать сервер, или `None`.

Транспорт может бросить `TimeoutError` — это тоже временный сбой.

## Требования

1. **Забрать все страницы.** Первый запрос идёт без курсора, дальше — с
   `next_cursor` из предыдущего ответа. Признак конца — `next_cursor is None`.

2. **Повторять только то, что имеет смысл повторять.** Временные сбои — это
   `429`, `5xx` и `TimeoutError`. Ошибки клиента (`400`, `401` и прочие `4xx`,
   кроме `429`) повторять бессмысленно: надо бросить `ApiError`.

3. **Задержка растёт.** Между попытками — пауза, увеличивающаяся
   экспоненциально: `base`, `base * 2`, `base * 4`… Пауза берётся через
   `sleep`, переданный аргументом (в тестах он поддельный, поэтому ничего не
   ждёт).

4. **`retry_after` важнее собственной задержки.** Если сервер прислал это
   поле, ждать надо столько, сколько он просит.

5. **Попытки кончаются.** После `max_attempts` неудач подряд — `ApiError` с
   внятным сообщением. Счётчик попыток сбрасывается после каждого успешного
   ответа: сбой на десятой странице не должен учитывать неудачи на второй.

6. **Защита от бесконечного цикла.** Если сервер начнёт возвращать один и тот
   же курсор, выгрузка обязана остановиться и бросить `ApiError`, а не
   крутиться вечно.

## Сигнатура

```python
def fetch_all(
    transport,
    limit: int = 100,
    max_attempts: int = 5,
    base_delay: float = 1.0,
    sleep=time.sleep,
) -> list[dict]:
```

`ApiError` уже объявлен в заготовке.

## Что проверяется

Открытые тесты показывают основные случаи. Скрытые проверяют то, что легко
упустить: сброс счётчика попыток, приоритет `retry_after`, рост задержки,
отсутствие повторов на `4xx`, остановку при повторяющемся курсоре и то, что
пустая первая страница не считается ошибкой.
