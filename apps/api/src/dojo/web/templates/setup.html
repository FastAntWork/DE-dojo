Как включить

1. Установи Docker Desktop

Скачать Docker Desktop →

Бесплатен для личного использования. При установке потребуются права администратора и, скорее всего, перезагрузка — Docker включает механизмы виртуализации Windows.

2. Запусти его и дождись зелёного значка

Docker Desktop должен быть запущен, а не просто установлен. Это самая частая причина того, что приложение по-прежнему не видит базу: значок кита в трее должен перестать мигать.

3. Перезапусти Dojo

uv run dojo start

Или просто закрой это окно и запусти Dojo.cmd заново. Первый запуск с Docker займёт несколько минут — скачиваются образы PostgreSQL и Redis, дальше секунды.
