# ADR 0005. Интерфейс на HTMX и Jinja вместо Next.js

- Статус: принято
- Дата: 2026-08-11

## Контекст

Раздел 5 исходного ТЗ предписывает Web UI на Next.js с Monaco и xterm.js.
К моменту, когда дошло до интерфейса, у проекта сложились три свойства,
с которыми этот выбор плохо согласуется.

Приложение офлайн-первое. Я отдельно убирал внешние реестры из сборки образа
(директиву `# syntax`, образ uv с ghcr) и вендорил ассеты Swagger UI, чтобы
`/docs` открывалась без интернета. Next.js возвращает зависимость от npm при
каждой сборке.

Приложение однопользовательское и локальное. Клиентский роутер, гидратация и
управление состоянием в браузере решают задачи, которых здесь нет: нет
конкурентных пользователей, нет задержек сети, нет SEO.

Бюджет памяти 10 ГБ. Node в контейнере сборки, `node_modules` на 300 МБ и
отдельный процесс — плата, за которую в этом проекте ничего не покупается.

## Решение

Интерфейс — серверный рендер на Jinja2 поверх уже работающего FastAPI, плюс
htmx для частичного обновления там, где перезагрузка страницы неуместна
(результат квиза). CSS пишется руками, без препроцессора и без шага сборки.

Monaco и xterm.js для M2 подключаются вендоренными файлами ровно так же, как
подключён Swagger UI: оба работают в любой странице и не требуют сборщика.

## Последствия

Ноль обращений к внешним хостам со страниц приложения — проверено тестом.
Ноль шагов сборки фронта: правка шаблона видна после перезапуска контейнера.
Требований к машине остаётся два: Docker и Python.

Чего лишаемся: богатых клиентских взаимодействий. Для графа, чтения теории и
квизов это не нужно. Если в M8 голосовое мок-интервью потребует сложного
состояния в браузере, отдельную страницу под него можно сделать на чём угодно
— серверный рендер остального этому не мешает.

Стилей нет из готовой библиотеки, поэтому за внешний вид отвечает
`static/app.css`. Это меньше кода, чем конфигурация Tailwind со сборкой, но
требует руки — при добавлении экранов нужно следить за единообразием.

Проверка ответов не дублируется между страницей и JSON-API: страница вызывает
ту же функцию. Два независимых судьи рано или поздно разошлись бы.
