# ADR 0004. Профили docker compose как следствие 16 ГБ на хосте

- Статус: принято
- Дата: 2026-08-10

## Контекст

Полный стек — Postgres, Redis, API, Ollama, Kafka, ClickHouse, Prometheus,
Grafana, MinIO, MongoDB, плюс стенд лабы — на машине с 16 ГБ не помещается.
WSL2 по умолчанию забирает половину памяти хоста, то есть 8 ГБ на всё.
Одна только модель 7B в q4 занимает около 5 ГБ.

Это не тот случай, когда «на проде будет больше»: прод здесь и есть ноутбук
пользователя.

## Решение

`.wslconfig` поднимает лимит WSL до 10 ГБ (плюс 8 ГБ свопа), Windows остаётся
около 5.5 ГБ.

Сервисы разложены по профилям compose, ничего не поднимается «на всякий
случай»:

| Профиль | Сервисы | Лимит |
|---|---|---|
| `core` (по умолчанию) | postgres, redis, api | 2.2 ГБ |
| `ai` | ollama | 7 ГБ |
| `analytics` | kafka, clickhouse, prometheus, grafana | 3.6 ГБ |
| `storage` | minio, mongodb | 1.1 ГБ |

У каждого сервиса выставлен `mem_limit`. Контейнер, вышедший за лимит,
убивается по OOM в одиночку — вместо того чтобы утащить за собой соседей.

Дополнительно ужимаются те, кто по умолчанию считает, что машина принадлежит
им целиком: `max_server_memory_usage` у ClickHouse, `wiredTigerCacheSizeGB` у
MongoDB, `KAFKA_HEAP_OPTS` у брокера.

Проброс GPU в ollama вынесен в отдельный оверлей `compose/ai.gpu.yml`: секция
device reservations роняет запуск на машине без `nvidia-container-toolkit`, а
его наличие не гарантировано. Лучше медленно на CPU, чем никак.

## Последствия

`ai` и `analytics` одновременно не работают. Практического ущерба нет: тьютор
нужен во время занятия, дашборд прогресса — между занятиями.

`make up PROFILE=full` предупреждает, если свободной памяти меньше нужного, но
не блокирует запуск — решение остаётся за человеком.

Каждый профиль обязан объявлять сеть `dojo` дословно одинаково: `external:
true` потребовал бы создавать её заранее руками.

Порт MinIO API переставлен на 9010 — 9000 занят нативным портом ClickHouse.

При появлении Runner-а (M2) добавится профиль `sandbox` с сетью без egress, и
правило «одновременно живёт максимум одна лаба» станет обязательным: свободной
памяти под второй стенд просто нет.
