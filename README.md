# DE Dojo

Локальный офлайн-тренажёр хард-скиллов Data Engineer.

Не курс и не сборник видео. Тренажёр: почти всё время ты что-то делаешь руками в реальных
окружениях, а система измеряет, что именно усвоено, и решает, что дать следующим.

## Пять принципов

1. **Проверка детерминированная, ИИ — только советник.** Зачёт ставят тесты, diff результата
   SQL-запроса и `check.py` внутри стенда. LLM объясняет, ревьюит стиль и ведёт интервью,
   но никогда не ставит зачёт по объективной задаче.
2. **Приложение написано на изучаемом стеке и само является учебным пособием.** Postgres, Redis,
   Kafka, ClickHouse, Docker, k8s, Grafana — одновременно инфраструктура Dojo и предмет изучения.
3. **Vacancy-driven.** Требования реальных вакансий перевзвешивают граф навыков.
4. **Интервалы и интерливинг** (FSRS) вместо линейного прохождения.
5. **Всё офлайн.** Интернет нужен только для первичной загрузки образов, датасетов и вакансий.

## Требования

| | |
|---|---|
| ОС | Ubuntu 22.04+ (в том числе внутри WSL2) |
| RAM | 16 ГБ минимум |
| Диск | 60 ГБ свободно (образы + модели + датасеты) |
| GPU | опционально; без неё LLM-роли работают на CPU и заметно медленнее |

## Быстрый старт

```bash
git clone <repo> ~/de-dojo && cd ~/de-dojo
bash tools/install-docker.sh   # только при первой установке
make doctor                    # проверит железо и подскажет профиль LLM
make up                        # поднимет core-профиль
make migrate
```

## Профили compose

Весь стек одновременно не влезает в 16 ГБ — и не должен. Сервисы разложены по профилям,
поднимается только то, что нужно прямо сейчас:

| Профиль | Сервисы | ~RAM |
|---|---|---|
| `core` (по умолчанию) | postgres, redis, api, web | 2.5 ГБ |
| `ai` | ollama | 6 ГБ |
| `analytics` | kafka (KRaft), clickhouse, grafana, prometheus | 4 ГБ |
| `storage` | minio, mongodb | 1 ГБ |
| `sandbox` | сеть без egress для Runner; максимум один стенд лабы | 2 ГБ |

```bash
make up                       # core
make up PROFILE=ai            # core + ai
make up PROFILE=full          # всё; предупредит, если RAM мало
```

## Устройство репозитория

```
apps/api       модульный монолит: content, scheduler, runner-client, ai, analytics
apps/runner    изолированный исполнитель пользовательского кода (отдельный сервис)
apps/web       Next.js + Monaco + xterm.js
apps/cli       dojo: next, submit, doctor, backup, content
content/       весь учебный материал как код: узлы графа, теория, задачи, лабы
migrations/    raw SQL, применяется alembic-обёрткой
infra/         конфиги grafana, prometheus, clickhouse, kafka, seccomp-профиль sandbox
docs/adr/      архитектурные решения и их причины
```

Учебный контент живёт в git, а не в БД. Таблицы `skills` / `tasks` — проекция YAML-файлов,
пересобираемая командой `dojo content sync`. Источник истины — файлы.

## Дорожная карта

| | | Готово, когда |
|---|---|---|
| M0 | скелет, compose, миграции, CI, `dojo doctor` | `make up` поднимает всё, CI зелёный |
| M1 | контент-сервис, граф, 3 узла SQL, web UI | видно граф, читается теория |
| M2 | Runner, sandbox, задания `sql` и `kata` | задача проверяется тестами реально |
| M3 | Scheduler: FSRS, mastery, «следующее задание» | приложение само ведёт по программе |
| M4 | AI service: Ollama, tutor, RAG по Postgres-докам | объяснение с цитатами работает офлайн |
| M5 | 5 лаб на docker-compose | стенд ломается и чинится, чекер честный |
| M6 | Analytics: события → Kafka → ClickHouse → Grafana | дашборд «моё обучение» живой |
| M7 | Vacancy-парсер и перевзвешивание графа | приоритеты меняются под рынок |
| M8 | Мок-интервью | 40-минутный собес с разбором |
| M9 | Наполнение контентом | ≥ 120 узлов, ≥ 30 лаб |

После M6 приложение полезно ежедневно — не откладывай использование до M9.

## Разработка

```bash
make lint        # ruff + format check
make typecheck   # mypy strict
make test        # unit (быстрые, без IO)
make test-int    # integration на testcontainers
```

Коммиты — [Conventional Commits](https://www.conventionalcommits.org/).
Архитектурные решения фиксируются в `docs/adr/` до того, как написан код.
